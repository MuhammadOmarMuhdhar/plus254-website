# Design Context

## Users
Developers, data scientists, researchers, and analysts who need programmatic access to Kenyan official statistics (economy, agriculture, governance data). They are technically literate, value clarity and speed, and need to trust the data source.

## Brand Personality
Trustworthy, precise, Kenyan. Three words: **clean**, **authoritative**, **warm**.

Emotional goals: evoke confidence in data quality and freshness; feel like a public utility done right—approachable but rigorous.

## Aesthetic Direction
Warm editorial minimalism with a distinct Kenyan identity. Think: *The Economist* meets *Gov.uk*—structured, readable, credible, but not cold.

- **Tone**: Professional but not corporate; warm neutrals with a single strong green accent.
- **Typography**: Newsreader (serif, display) + DM Sans (sans-serif, UI). Serif for headings, sans-serif for body.
- **Colors**: Green `#1f6f54` (primary), green-bg `#6cb999` (card surfaces), ochre `#1e3a5f` (secondary), warm-dark/mid/light (`#1a1a1a`, `#4a4540`, `#6b6560`) for text hierarchy. White backgrounds.
- **Layout**: Centered single-column hero, 2–3 column card grids, sticky sidebar navigation on inner pages. 960px max-width content.
- **Background**: 20px grid pattern at `rgba(108, 185, 153, 0.15)` on white.
- **Animation**: Subtle CSS-only micro-interactions — hover lifts on cards (`translateY(-3px)`), button scale (`1.03`), `ease-out-quart` easing. No entrance/scroll animations. `prefers-reduced-motion` kills all transitions.
- **Theme**: Light mode only.

## Design Principles
1. **Trust through restraint** — every element earns its place; no decorative noise.
2. **Hierarchy through type** — size and weight, not boxes and borders, create structure.
3. **Performance is polish** — fast loads, no layout shift, smooth 60fps transitions.
4. **Accessibility is non-negotiable** — WCAG AA contrast, visible focus states, keyboard navigation, `prefers-reduced-motion` respected.
5. **Animation with purpose** — interaction feedback only (hover/active/focus), no page-load or scroll-triggered animations. Subtle and invisible.

## Site Features
- Featured data section with embedded Datawrapper iframe chart
- API documentation pages with language tab switchers (curl/Python/JavaScript)
- Scroll-spy sidebar navigation on About and Datasets pages
- Mobile hamburger menu, responsive breakpoints at 900px/768px/480px
